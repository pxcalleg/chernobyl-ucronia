# Chernobyl Ucronia - Il disastro sventato

Avventura testuale in italiano, in stile anni 80. Pripyat, 25 aprile 1986: sei Pavel Sorokin, giovane ingegnere appena arrivato. Hai una notte per scoprire il difetto delle barre di controllo del reattore 4 e impedire che il test delle 01:23 finisca come nella storia vera.

## Come si gioca
Apri `index.html` nel browser, oppure la pagina GitHub Pages del repository. Scrivi i comandi in italiano (VAI NORD, PRENDI, LEGGI, PARLA CON, DAI, MOSTRA...). Scrivi AIUTO per l'elenco completo e SPIEGA <termine> per i termini tecnici.

## File
- `index.html`: lo schermo a fosfori verdi.
- `game.js`: il motore del gioco (luoghi, personaggi, enigmi, la notte).

Il concept completo è in `docs/`.
